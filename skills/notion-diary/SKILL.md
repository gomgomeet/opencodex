# 노션 다이어리 저장 (notion-diary)

대화에서 나온 계획·할 일·기록을 사용자의 노션 다이어리 DB에 **바로 실행 가능한
액션 체크리스트** 형태로 저장한다.

## 저장 위치 (고정)

- 데이터베이스: **📓 다이어리 —해야 할 일 액션 위주로**
- 데이터 소스 ID: `830c5f01-a4a4-82a5-b840-87de7a8a4c79`
- 위치: 곰곰 업무 대시보드 아래

`notion-create-pages`에 `{"type": "data_source_id", "data_source_id":
"830c5f01-a4a4-82a5-b840-87de7a8a4c79"}` 를 parent로 넘긴다.
노션 커넥터 도구가 없으면 **아무것도 하지 말고** 커넥터를 켜달라고만 안내한다.

## 속성 채우기 규칙

| 속성 | 규칙 |
|------|------|
| `제목` | 이모지 1개 + 한 줄 요약 (예: "🎬 오늘 저녁 집컴: 편집 스킬 세팅") |
| `date:날짜:start` | 오늘 날짜 (KST 기준, YYYY-MM-DD). 사용자가 다른 날짜를 말하면 그 날짜 |
| `유형` | 아래 선택 규칙 참조 — 4개 옵션 외 값 금지 |
| `오늘의 한 줄` | 내용 전체를 한 문장으로 압축 |

**유형 선택 규칙** (select, 정확히 이 4개만 존재):
- `수업일지` — 수업·학생·교실 관련
- `업무일지` — 그 외 업무, 프로젝트, 세팅, 연수 준비 (기본값)
- `상담기록` — 학부모·학생 상담
- `감사한 일` — 감사·회고성 기록

애매하면 `업무일지`로 하고, 저장 후 보고에서 유형을 언급해 사용자가 바꿀 수 있게 한다.

## 본문 작성 규칙

이 다이어리는 "해야 할 일 **액션 위주**"가 컨셉이다. 감상문이 아니라 실행 문서로 쓴다.

1. **체크리스트가 중심** — 할 일은 전부 `- [ ]` 체크박스로. 사용자가 하나씩
   지워가며 진행할 수 있어야 한다.
2. **필요한 명령·링크를 본문에 직접 포함** — "아까 그 명령어"라고 쓰지 말고
   실제 코드 블록·URL을 붙여넣는다. 다이어리만 열면 대화를 다시 찾지 않고
   실행할 수 있어야 한다.
3. **단계가 여럿이면 ①②③ 섹션**으로 나누고 각 단계에 예상 소요 시간을 적는다.
4. **막혔을 때의 대안**도 한 줄씩 넣는다 (예: "pip 못 찾으면 python -m pip ...").
5. 끝에 관련 맥락(진행 상황, PR 링크 등)을 한 줄로.

## 절차

1. 대화 내용에서 저장할 것을 정리한다. 무엇을 저장할지 모호하면 **직전에 논의된
   계획/할 일**을 기본으로 하되, 저장 전에 제목 한 줄로 확인받는다
   (사용자가 명확히 지정했으면 바로 진행).
2. 같은 날짜에 같은 주제의 항목이 이미 있는지 확인한다 — 있으면 새로 만들지 말고
   기존 페이지에 내용을 추가할지 물어본다 (중복 금지).
3. 페이지를 생성하고 **제목·날짜·유형·링크를 보고**한다.
4. 기존 페이지를 수정·삭제하지 않는다. 이 스킬은 생성만 한다
   (2번의 '기존 페이지에 추가'는 사용자가 승인한 경우만).
