# 강의 동영상 편집 툴 (lecture-video-editor 스킬) PRD

> 작성일 2026-08-12 · 상태: 초안(리뷰 대기)

## Objective

강사(사용자 본인)가 녹화한 강의 동영상을 "원본 → 배포 가능한 완성본"까지
만드는 데 드는 편집 시간을 회당 수 시간에서 30분 이내로 줄이는 편집 툴을
만든다. 형태는 별도 GUI 앱이 아니라 **Claude Code 스킬(`lecture-video-editor`)
+ 로컬 CLI 파이프라인(ffmpeg/Whisper)** 이다. 사용자는 자연어로 지시하고
("이 영상 무음 잘라내고 자막 붙여줘"), Claude가 분석 → 편집안 제안 → 승인 후
렌더링하는 흐름을 따른다.

## 배경 / 문제

- 사용자는 교원 연수 강의(지식샘터 원격연수, 대면 연수 녹화, 유튜브 업로드용
  강좌)를 정기적으로 녹화한다. 교안(`edu-training-deck`), 강좌 소개
  (`edu-course-listing`), 썸네일(`edu-thumbnail`) 등 강좌 제작의 앞뒤 공정은
  이미 스킬로 자동화되어 있으나 **가운데 공정인 영상 편집만 수작업**으로
  남아 있다.
- 수작업 편집의 병목:
  1. 말 더듬/버벅임/무음 구간을 타임라인에서 눈으로 찾아 자르는 시간이 가장 크다.
  2. 자막(한국어) 생성·교정을 별도 서비스에서 다시 해야 한다.
  3. 플랫폼별 규격(지식샘터 차시별 분량, 유튜브 챕터·해상도)을 매번 수동으로 맞춘다.
  4. 화면 녹화에 학생 이름·개인정보가 노출될 수 있어 배포 전 검수가 필요하다.
- 스킬 마켓 조사 결과(2026-08-12): 동영상 편집/ffmpeg/자막 관련 기존 스킬
  **없음** → 신규 제작이 필요하다.

## 사용자 & 핵심 시나리오

대상 사용자는 1인(강사·교사). 멀티테넌시·계정·클라우드 업로드는 범위 외.

| # | 시나리오 | 입력 | 출력 |
|---|---------|------|------|
| S1 | 자동 컷 편집 | 원본 mp4/mov (60–120분) | 무음·버벅임 제거된 편집본 + 컷 리스트 |
| S2 | 자막 생성 | 편집본 | 교정된 SRT/VTT + 하드섭 옵션 |
| S3 | 챕터·목차 | 자막(전사) | 유튜브 챕터 텍스트, 차시 분할 지점 제안 |
| S4 | 개인정보 검수 | 편집본 | 노출 구간 타임스탬프 리포트 + 블러 처리 |
| S5 | 규격 인코딩 | 편집본 | 플랫폼 프리셋별 최종 mp4 |
| S6 | 클립 추출 | 완성본 | 홍보용 쇼츠(세로 1080×1920) 후보 클립 |

## 기능 요구사항

### P0 — MVP

- **F1. 무음/필러 컷 편집**: ffmpeg `silencedetect` + Whisper 전사 결과로
  무음(기본 1.5s↑)과 필러("어…", "음…", 반복 문장) 구간을 찾아
  **EDL(컷 리스트) 파일을 먼저 제안**하고, 사용자가 마크다운 표에서 승인/수정한
  뒤에만 렌더링한다. 원본은 절대 덮어쓰지 않는다(비파괴).
- **F2. 한국어 자막**: faster-whisper(large-v3, 로컬)로 전사 → Claude가
  교육 용어·고유명사(예: 지식샘터, 위두랑) 교정 → SRT/VTT 출력.
  자막 굽기(하드섭)는 옵션.
- **F3. 인코딩 프리셋**: `youtube`(1080p H.264 CRF 18), `knowledge-teacher`
  (지식샘터 업로드 규격), `archive`(원본 화질 보존) 3종. 프리셋은 스킬 내
  설정 파일로 관리해 추가 가능.
- **F4. 작업 리포트**: 편집 전후 길이, 잘린 구간 수/총량, 자막 라인 수를
  요약한 리포트를 매 실행마다 남긴다(재현 가능하도록 EDL·명령어 포함).

### P1

- **F5. 챕터/차시 분할**: 전사 내용 기반으로 주제 전환 지점을 찾아 유튜브
  챕터 텍스트를 생성하고, 지식샘터용 차시(예: 25분 단위) 분할 지점을 제안.
- **F6. 개인정보 스캔**: 화면 녹화 프레임 샘플링 + 전사 텍스트에서 학생
  실명·연락처·기관 내부 정보 노출 후보를 타임스탬프로 리포트. 블러/컷 처리는
  사용자 확인 후 적용. **모든 처리는 로컬에서 수행**(영상을 외부 API에
  업로드하지 않는다 — 교육 콘텐츠 특성상 필수 제약).
- **F7. 인트로/아웃트로**: 곰곰이쌤 브랜드 인트로·아웃트로 클립을 앞뒤에
  concat. 썸네일은 기존 `edu-thumbnail` 스킬 산출물을 그대로 연계.

### P2

- **F8. 쇼츠 클립 추출**: 전사에서 하이라이트 후보를 골라 세로형 클립 생성
  (자막 크게 굽기 포함).
- **F9. 강좌 파이프라인 연결**: 완성본 메타데이터(제목·챕터·요약)를
  `edu-course-listing` 스킬 입력으로 넘겨 강좌 소개문까지 한 흐름으로 생성.

## 비기능 요구사항

- **로컬 우선**: 영상·음성 원본은 로컬에서만 처리. LLM에는 전사 텍스트와
  메타데이터만 전달한다.
- **비파괴**: 원본 파일 보존, 산출물은 `output/<날짜>_<제목>/` 아래 생성.
- **재현성**: 모든 렌더는 EDL + ffmpeg 명령 로그로 재실행 가능해야 한다.
- **성능 목표**: 60분 1080p 원본 기준 전사+컷 제안까지 15분 이내
  (Apple Silicon 로컬 기준), 렌더는 실시간의 0.5배 이내.
- **의존성**: ffmpeg, faster-whisper(Python). 스킬 첫 실행 시 설치 여부를
  점검하고 없으면 설치 안내를 출력한다.

## 아키텍처 개요

```
원본 영상 ─▶ [1] 분석: ffprobe / silencedetect / faster-whisper 전사
          ─▶ [2] 제안: Claude가 컷 리스트(EDL)·자막 교정·챕터 초안 생성
          ─▶ [3] 승인: 사용자가 표에서 수정/승인 (여기서만 사람 개입)
          ─▶ [4] 렌더: ffmpeg concat/filter로 편집본·자막·프리셋 인코딩
          ─▶ [5] 리포트 + (P1~) 개인정보 스캔·챕터·연계 산출물
```

- 스킬 구조: `SKILL.md`(트리거·워크플로) + `scripts/`(분석·렌더 파이썬/셸
  스크립트) + `presets/`(인코딩 프리셋) + `templates/`(리포트·EDL 양식).
- 제작은 `skill-creator` 스킬로 진행하고, 평가용 샘플 영상 2–3개로 시나리오
  S1·S2 회귀 테스트를 만든다.

## 범위

- IN: 위 F1–F9, 스킬 패키징, 사용 가이드 문서.
- OUT: GUI 타임라인 편집기, 실시간 스트리밍 편집, 다국어 자막 번역(추후),
  클라우드 렌더팜, 이 리포(opencodex) 프록시 코어와의 코드 결합 —
  본 문서는 이 리포를 작업 기록 장소로만 사용하며 산출물 스킬은 독립 배포한다.

## 성공 지표

- 60분 강의 기준 편집 소요 시간: 수작업 대비 80%↓ (목표 30분 이내, 사람 개입은
  컷 리스트 승인 + 자막 검수만).
- 자막 초안 정확도: 교정 후 재수정 라인 10% 미만.
- 배포 전 개인정보 노출 사고 0건.

## 마일스톤

| 단계 | 내용 | 완료 기준 |
|------|------|-----------|
| M1 | 스킬 골격 + F1(무음 컷) | 샘플 영상에서 EDL 제안→승인→렌더 왕복 성공 |
| M2 | F2(자막) + F3(프리셋) + F4(리포트) | 60분 영상 엔드투엔드 30분 내 처리 |
| M3 | F5–F7 (챕터·개인정보·브랜딩) | 지식샘터 1개 강좌 실전 투입 |
| M4 | F8–F9 (쇼츠·강좌 연계) | 유튜브 업로드 1건 전 과정 스킬로 완료 |

## 검증

- 샘플 강의 영상(무음·버벅임 포함 10분 클립)으로 S1–S2 자동 테스트.
- 실제 강의 1편으로 M2 파일럿 → 소요 시간·재수정률 측정 후 지표 갱신.

## 오픈 퀘스천

1. 지식샘터 업로드 규격(해상도·용량·컨테이너)의 정확한 최신 값 — 사용자 확인
   필요(F3 프리셋 확정 전).
2. 녹화 소스 종류(줌 녹화 / OBS 화면녹화 / 캠 합성 여부)에 따라 F6 개인정보
   스캔 범위가 달라짐 — 파일럿 때 실제 원본으로 확정.
3. 인트로/아웃트로 클립 원본 보유 여부(F7) — 없으면 `canvas-design` 계열로
   제작하는 하위 작업 추가.
